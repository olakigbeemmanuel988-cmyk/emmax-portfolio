# Emmax Portfolio

A professional 3D-themed portfolio landing page for **Emmax** — Digital Marketing Specialist, Website Developer & E-commerce Expert.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite 7**
- **Tailwind CSS 4**
- **Three.js** + **@react-three/fiber** + **@react-three/drei** (3D hero scene)
- **Motion (Framer Motion 12)** (animations)
- **Lucide React** (icons)
- **Sonner** (toasts)

## Sections

1. Hero — 3D animated background with floating geometry
2. Stats — Animated count-up numbers
3. About — Professional photo with orbital rings and floating tags
4. Services — 4 cards with mouse-tracking 3D tilt hover effects
5. Portfolio — 6 project cards with metrics
6. Skills — Animated progress bars + certifications
7. Testimonials — 6 client reviews
8. Process — 7-step workflow
9. FAQ — Accordion
10. Contact — Form that sends directly via WhatsApp
11. Footer

## Getting Started

```bash
npm install
npm run dev
```
